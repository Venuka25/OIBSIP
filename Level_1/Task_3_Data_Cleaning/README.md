# Oasis Infobyte Internship – Task 3: Cleaning Data

## Objective
To clean a messy dataset using Python, Pandas and NumPy.

## Dataset
Titanic Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Work Performed
- Loaded and inspected the dataset.
- Checked missing values and duplicate records.
- Handled missing values using suitable methods.
- Removed duplicate rows.
- Standardized categorical values.
- Corrected data types.
- Detected outliers using the IQR method.
- Compared data before and after cleaning.
- Saved the cleaned dataset as a CSV file.

## Conclusion
The Titanic dataset was cleaned successfully. Data quality and consistency were improved using Python and Pandas.
